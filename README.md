Консольное Java-приложение для управления списком студентов. 
Выполнено в рамках работы по дисциплине "Специализированные инструменты прикладного программирования".

## Функционал

### 1. Базовый
- Класс `Student` с полями: имя, средний балл, номер зачетной книжки
- Консольное меню, работающее циклично до момента выбора пользователем пункта "Выход"
- Добавление студентов вручную и импорт из файла
- Валидация данных (`StudentValidator`, `InvalidStudentDataException`)
- Обработка исключений через `try-catch` и `try-with-resources`
- Stream API: `filter`, `map`, `sorted`, вывод результатов в консоль

### 2. Собственная коллекция
- `CustomArrayList<T>`, аналог `ArrayList`
- Операции `add`, `get`, `set`, `remove`, `size`, `isEmpty`
- Автоматическое расширение внутреннего массива
- Используется вместо `java.util.ArrayList` во всем проекте

### 3. Собственные алгоритмы сортировки
- Интерфейс `SortAlgorithm<T>` , в котором применен полиморфизм и Generics
- Реализации алгоритмов сортировки : `BubbleSortAlgorithm`, `QuickSortAlgorithm`
- Выбор алгоритма, поля и направления сортировки через меню

### Сборка:

```mvn clean package```

### Запуск:

```java -jar target/student-manager-jar-with-dependencies.jar```

### Сборка без тестов:

```mvn clean package -DskipTests```

### Запуск тестов:

```mvn test```

## Меню приложения

```
1. Добавить студента вручную
2. Импортировать список студентов из файла
3. Показать список студентов
4. Отфильтровать студентов по среднему баллу (Stream API)
5. Вывести описания студентов (Stream API, map)
6. Отсортировать студентов (Stream API)
7. Отсортировать студентов (выбор алгоритма, поля и направления)
8. Экспортировать список студентов в файл
0. Выход
```
В пункте 7 пользователь последовательно выбирает поле сортировки (имя, балл или номер зачетной книжки), направление (возрастание или убывание) и алгоритм (пузырек либо быстрая сортировка)

## Формат файла с данными
Файл состоит из строк следующего формата: 
```Имя,СреднийБалл,НомерЗачётки```

### Пример (data/students.txt):

```
Иванов Иван,4.8,AB-12345
Петров Петр,3.2,AB-12346
Сидорова Анна,2.1,AB-12347
Кузнецова Мария,5.0,AB-12348
,4.0,AB-99999
Смирнов Олег,6.5,AB-12349
Фёдоров Денис,3.9,
Орлова Светлана,4.4,AB-12350
```
Стоит заметить, что последние три строки намеренно некорректны и при импорте пропустятся с выводом сообщения об ошибке

## Ключевые классы
- `Student` - модель данных с полями, геттерами, сеттерами, equals/hashCode/toString
- `StudentValidator` - проверка имени, диапазона балла, формата зачетки
- `CustomArrayList<T>` - реализованная коллекция, динамический массив на основе Object[]
- `SortAlgorithm<T>` - интерфейс сортировки, принимает коллекцию и компаратор
- `BubbleSortAlgorithm`, `QuickSortAlgorithm` - реализации алгоритмов сортировки
- `FileService` - чтение и запись файлов через try-with-resources
- `StudentService` - обработка данных через Stream API, выбор компаратора
- `Main` - точка входа, логика консольного меню
